# ui-lab

UI components I'm building to learn interaction design.

```bash
bun install
bun dev
```

Add a component with `bun run new <slug>`. Built on [design-scaffold](https://github.com/xevrion/design-scaffold).

Take one home with the shadcn CLI, or give your agent the skill:

```bash
npx shadcn@latest add https://lab.xevrion.dev/r/<slug>.json
npx skills add xevrion/ui-lab
```
